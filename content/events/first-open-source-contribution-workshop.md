Have you ever wanted to contribute to open source but weren't sure where to begin? This
hands-on workshop is for you.

Join PyLadies Vancouver for a friendly, beginner-focused workshop on contributing to open
source in Python. Together we'll go from "I've never contributed before" to opening a real
pull request, with plenty of support at every step. No prior contribution experience is
needed. If you can write a little Python, you belong here.

Open source runs on far more than code, and there are many ways to get involved. We'll
show you how to find your footing and give you the confidence to keep contributing long
after the workshop ends.

## What we'll cover

Working together on a friendly practice project, you'll get hands-on with:

- Getting started in open source, and the many ways to get involved
- Finding projects and issues that are a good fit for you
- Git and GitHub for contributors: forking, branching, commits, and pull requests
- Contributing documentation
- Packaging a Python project
- Continuous integration and CI/CD

By the end, you'll have walked the whole contribution journey from start to finish on a
real repository, and you'll know exactly how to take that first step on a project you care
about.

## Who it's for

Anyone comfortable writing a little Python who is new to, or curious about, contributing
to open source. Everyone is welcome.
